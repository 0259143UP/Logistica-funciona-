# KargoPulse MX — Plataforma Predictiva de Logística y Fletes en México

Accede a la plataforma en vivo aquí: https://kargopulse-mx.streamlit.app

Plataforma de Big Data y Machine Learning (PySpark, Databricks Delta Lake y HistGradientBoosting) para estimación de tiempos de ruta, tarifas de fletes y riesgo de retrasos en México.
